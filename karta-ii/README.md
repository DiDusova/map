# Карта возможностей ИИ

Интерактивная карта Школы Экзомышления: что ИИ умеет в работе, на каком уровне усиления и что работает в России. Срез на 06.10.2026.

Сайт статический: только HTML, CSS и JavaScript, без сервера и базы данных. Все ресурсы лежат в репозитории (шрифты и библиотека QR-кода локальные), внешних подключений нет, поэтому страницы открываются в России без VPN.

## Что внутри

| Файл | Что это |
|---|---|
| `index.html` | Интерактивная радиальная карта: зоны, сценарии, карточки. Главная страница |
| `spravochnik.html` | Справочник: лестница усиления, сценарии, 30 вопросов, антикарта, цифры |
| `qr.html` | Страница с QR-кодом на адрес сайта, для показа на экране и печати |
| `favicon.svg`, `assets/` | Иконка, шрифт Manrope, библиотека QR-кода (MIT) |
| `src/` | Исходники: данные, тексты, шаблоны и скрипт сборки |

## Шаг 1. Загрузить в GitHub

1. На github.com нажмите **New repository**, назовите, например, `karta-ii`. Видимость: Public или Private (для Timeweb подходят обе).
2. В пустом репозитории нажмите **uploading an existing file**.
3. Перетащите в окно всё содержимое этой папки: файлы `index.html`, `spravochnik.html`, `qr.html`, `favicon.svg`, `README.md` и папки `assets` и `src`. Важно перетаскивать содержимое, а не саму папку, чтобы `index.html` оказался в корне репозитория.
4. Нажмите **Commit changes**.

## Шаг 2. Разместить на Timeweb

### Вариант А. Timeweb Cloud, раздел «Apps» (рекомендую: обновляется сам при изменениях в GitHub)
1. В панели Timeweb Cloud откройте **Apps** и создайте приложение типа **Frontend**.
2. Подключите аккаунт GitHub и выберите репозиторий `karta-ii`, ветку `main`.
3. Сборка не нужна. Если панель просит выбрать фреймворк, выберите вариант для обычного HTML (статический сайт без сборки). Команду сборки оставьте пустой, директория с готовыми файлами: корень репозитория.
4. После деплоя приложение получит технический адрес. Свой домен можно привязать в настройках приложения.

Названия пунктов в панели могут немного отличаться: ориентируйтесь на «Apps → Frontend → GitHub → без сборки».

### Вариант Б. Обычный хостинг Timeweb
1. В файловом менеджере хостинга откройте папку сайта (обычно `public_html`).
2. Загрузите туда всё содержимое этой папки так, чтобы `index.html` лежал прямо в `public_html`.

## Шаг 3. QR-код

1. Откройте `https://ваш-адрес/qr.html`. Страница сама построит QR-код на адрес вашего сайта.
2. Покажите её на экране или нажмите **Печать**. Кнопка **Скачать SVG** сохраняет код в векторе для слайда или раздатки.
3. Если нужен QR на другой адрес (например, на свой домен), впишите его в поле и нажмите **Обновить**.

Человек наводит камеру телефона на код и сразу попадает на интерактивную карту. На телефоне карта сверху, под ней панель с зонами, сценариями и карточками.

## Как обновлять карту

1. Правьте карточки в `src/data.json`, а тексты лестницы, зон и вопросов в `src/manual.js`.
2. Запустите сборку из корня репозитория: `python3 src/build.py`. Она пересоберёт `index.html` и `spravochnik.html`.
3. Загрузите изменённые файлы в GitHub. В варианте А Timeweb обновит сайт сам.

## Проверка после размещения

- Откройте сайт с телефона в мобильной сети без VPN.
- Нажмите любую зону, переключитесь на «По сценариям», откройте карточку.
- Откройте `qr.html` и отсканируйте код другим телефоном.
